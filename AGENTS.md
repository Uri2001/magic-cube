# AGENTS

## Исходное задание

Написать однофайловый HTML/CSS/JS-проект. Страница должна отображать интерактивную 3D-модель кубика Рубика, с которой можно взаимодействовать: поворачивать грани мышью и клавишами, поворачивать кубик в произвольных направлениях. Нужно рассмотреть инструменты для качественного проекта, создать файл с исходным заданием, требованиями и ограничениями агентов, а также `README.md` с описанием проекта и особенностей кода.

## Требования

- Основное приложение должно оставаться однофайловым: `index.html` содержит HTML, CSS и JavaScript.
- Для качественной 3D-сцены используется Three.js через CDN и ES module import map.
- Проект должен поддерживать:
  - свободное вращение камеры мышью без ограничения вертикального оборота;
  - поворот граней клавишами `U D L R F B`;
  - соответствие клавиш граней текущей визуальной ориентации после поворотов всего куба и камеры;
  - обратные ходы через `Shift`;
  - поворот всего куба клавишами `X Y Z` вокруг собственных осей куба;
  - поворот слоя drag-жестом по цветной наклейке;
  - scramble и reset.
- Reset должен возвращать состояние cubie, ориентацию всего куба и камеру к начальному виду.
- UI должен быть адаптивным и не должен перекрывать основную 3D-модель на малых экранах.
- README должен описывать запуск, управление и архитектуру.

## Ограничения для агентов

- Не добавлять сборщик, package manager, фреймворк или дополнительные runtime-файлы без отдельного запроса.
- Не разбивать `index.html` на отдельные CSS/JS-модули.
- Не заменять Three.js CDN на другую библиотеку без явной причины.
- Не добавлять тяжелые текстуры или бинарные ассеты; модель должна строиться процедурно.
- После изменений проверять, что сцена рендерится, куб виден, клавиши работают, а UI не ломается на desktop и mobile ширине.
- Сохранять существующие пользовательские изменения и не выполнять destructive git-команды без явного запроса.
