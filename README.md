# Magic Cube

Однофайловый HTML/CSS/JS-проект с интерактивной 3D-моделью кубика Рубика. Сцена построена на Three.js, а все стили и логика находятся в `index.html`.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из папки проекта:

```powershell
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Проект использует Three.js и `TrackballControls` через CDN, поэтому для первого запуска нужен доступ к интернету.

## Управление

- Мышь по фону: свободное вращение камеры вокруг куба без ограничения вертикального оборота.
- Drag по цветной наклейке: поворот слоя, который лучше всего соответствует направлению жеста.
- `U D L R F B`: поворот соответствующих граней в текущей визуальной ориентации куба и камеры.
- `Shift + U/D/L/R/F/B`: обратный поворот грани.
- `X Y Z`: поворот всего куба вокруг собственных осей куба.
- `Space`: перемешать куб.
- `Backspace`: сбросить состояние, ориентацию куба и вид камеры.

## Особенности реализации

- Куб собран из 27 независимых cubie-групп, у каждой хранится координата слоя `x/y/z`.
- Цветные наклейки и внешние черные поверхности cubie участвуют в hit-test, поэтому drag можно начинать не только строго внутри цветного квадрата.
- Drag по наклейке анализируется геометрически: приложение запоминает точку и нормаль нажатой поверхности, переводит движение мыши в 3D-вектор на плоскости этой поверхности и выбирает слой, чей поворот лучше всего совпадает с этим вектором.
- Поворот слоя выполняется через временную `THREE.Group`: выбранные cubie временно прикрепляются к ней, а после анимации возвращаются в общий контейнер.
- После каждого хода координаты cubie пересчитываются дискретно, а позиции привязываются к сетке, чтобы модель не расползалась после серии ходов.
- После поворотов всего куба клавиши граней вычисляют текущий верхний/нижний/левый/правый/передний/задний слой по ориентации общего контейнера и экранным осям камеры.
- Повороты всего куба выполняются через quaternion-анимацию, поэтому оси куба остаются стабильными после серии `X/Y/Z`-ходов.
- Начальная ориентация куба соответствует мировым осям: белая грань направлена по `+Y`, красная по `+X`, а синяя и зеленая лежат на оси `Z`.
- Интерфейс не требует сборки, package manager или отдельных ассетов.

## Ограничения

- Это визуальная и интерактивная модель, а не полный Rubik solver.
- Для почти диагональных drag-жестов выбирается ближайшее направление на плоскости нажатой грани, поэтому намерение пользователя оценивается по наиболее вероятному ходу.
- При открытии без интернета CDN-импорты Three.js не загрузятся.
